# Automation Utilities 

A main repository containing AI microservices and pipelines.


### 1. Local Product Optimizer (`LocalProductOpt`)
A self-hosted, **GDPR-compliant** e-commerce microservice designed to automate SEO text optimization pipelines for **Shopware** frameworks locally.

* **Tech Stack:** Python, FastAPI, Pydantic v2
* **Local Run Command:** 
  docker compose up --build
